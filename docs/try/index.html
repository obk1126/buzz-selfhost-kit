에이전트 크루 직접 써보기

김우빈 개인 R&D 서버의 상주 에이전트에 실시간으로 연결됩니다 · 사례 설명 · 재현 킷

아래 두 가지는 녹화나 시뮬레이션이 아니라, 지금 이 순간 제 서버에서 실제로 돌아가는 에이전트입니다. 데모 에이전트는 격리 워크스페이스에서 셸·파일 도구가 차단된 상태로 동작합니다.

하루 사용량이 제한된 데모라 코드가 필요합니다.

1. 안내 에이전트와 대화

이 체계가 뭘 하는지 직접 물어보세요. 예: "교차 검증은 어떻게 하는 거야?", "운영하면서 뭐가 제일 어려웠어?"

접근코드를 입력하고 메시지를 보내면 에이전트가 응답합니다. (응답에 10~30초 걸립니다)

2. 크루 협업 관전 — 작성 → 적대적 검증 → 수정

과제를 투입하면 작성 에이전트가 초안을 쓰고, 검증 에이전트가 "빠진 것 · 틀린 가정 · 약한 근거" 3가지를 지적하고, 작성 에이전트가 지적을 반영해 최종본을 만듭니다. 제 크루가 실제 산출물을 다루는 방식 그대로입니다. (총 1~3분)
